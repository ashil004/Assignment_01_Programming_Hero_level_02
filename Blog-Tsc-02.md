During compilation (tsc), TypeScript removes all type information and turns your code into plain JavaScript. The tsconfig.json file works like a control center that tells the compiler how to do this job. To handle different types of data safely, you can use union types along with typeof checks or switch statements. You can also use readonly tuples to stop people from changing your data by mistake.To write code that works with many data types, generic functions and keyof rules make your work reusable and safe. For building big applications, object-oriented features like classes, extends, super(), and private properties help you organize and protect your code. Finally, using promises helps you handle tasks that take time to finish without freezing your program. Together, these simple tools catch errors early and make your code easier to manage.
